# Contributing to Final AI Assistant

Thank you for your interest in improving Final AI Assistant. Contributions are welcome and appreciated.

## How to Contribute

1. Fork the repository.
2. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes with clear, focused commits.
4. Test your changes locally.
5. Submit a pull request with a clear description of the improvement.

## Contribution Guidelines

- Keep changes focused and easy to review.
- Follow the existing code style and naming conventions.
- Update documentation if your change affects setup, usage, or behavior.
- Avoid introducing unused dependencies.
- Make sure the app still runs with `streamlit run src/final_chatbot.py`.

## Reporting Issues

If you find a bug or want to request a feature, please include:

- A short summary
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots or error messages if available

## Pull Request Checklist

- Code is clean and readable
- Documentation is updated if needed
- No unrelated changes are included
- The application has been tested locally

Thank you for helping improve the project.
